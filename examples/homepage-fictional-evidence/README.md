# Fictional evidence-structure examples

This directory contains compact CC0 research fixtures used only to demonstrate how PostEx evaluates evidence structure across study types on the GitHub landing page.

- AURORA-12, under `examples/aurora-synthetic/`, represents a synthetic bioinformatics workflow.
- LUMEN-24 represents a synthetic observational cohort workflow.

Every title, cohort, center, exposure, endpoint and result is authored for software evaluation. Nothing here is biomedical evidence, and no real participant, institution, dataset, DOI or study is represented.
