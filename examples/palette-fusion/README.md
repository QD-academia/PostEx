# Palette Fusion example

This design-stage example demonstrates a confirmed Poster Brief, role-based Palette DNA, three structurally different fusion candidates, and an HTML design rationale.

```bash
postex palette-plan examples/palette-fusion/project.yaml
postex fusion-plan examples/palette-fusion/project.yaml
```

The named theme is expressed only through user-authored mood words and hexadecimal colors. No third-party character artwork, logo, font, or game asset is included or licensed by this example.
