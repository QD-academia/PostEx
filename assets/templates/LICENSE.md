# Template asset license registry

The placeholder metadata and original placeholder notes in this directory are licensed under CC BY 4.0, attributed to PostEx contributors.

This is intentionally separate from the Apache-2.0 software license. Every future `.pptx`, preview, icon, font, logo, and example figure must have a machine-readable license field and a nearby provenance record. A template may not be released when any embedded asset has unknown or incompatible terms.

Third-party assets are not included in this skeleton.
