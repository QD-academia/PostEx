# Contributing

Thank you for improving PostEx.

1. Open an issue before changing public schemas, approval semantics, privacy defaults, or template dimensions.
2. Create a focused branch and keep the shared core provider-neutral.
3. Add or update tests, schemas, docs, examples, and the changelog together.
4. Run `python -m unittest discover -s tests -v` and `python scripts/check_repository.py`.
5. Never add unpublished manuscripts, credentials, proprietary fonts, unlicensed figures, or real personal data.
6. Record every template and example license independently from the Apache-2.0 code license.

Commit messages should explain user-visible behavior. Pull requests must describe privacy impact, evidence-traceability impact, rendering impact, and testing performed.

By contributing, you agree that your contribution is licensed under Apache-2.0 unless a file is clearly identified as a separately licensed asset.
