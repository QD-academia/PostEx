# Asset licensing

Apache-2.0 covers source code and repository documentation unless stated otherwise. It does not automatically cover templates, examples, fonts, figures, logos, papers, or datasets.

Each asset record must identify SPDX expression, copyright holder, source URL, retrieval date, modification status, attribution text, redistribution permission, and figure-reuse restrictions. Unknown license means the asset cannot ship.

Current fictional examples use CC0-1.0. Current original template placeholders use CC BY 4.0. The GitHub homepage showcase bundles separately governed third-party media solely for attributed, non-commercial documentation: one HoYoverse-hosted Varka illustration, one CC BY 3.0 Temple of Heaven photograph, and two CC BY-NC 4.0 scientific-poster previews. See `docs/images/showcase/README.md`; none of these files are covered by Apache-2.0.

Palette Fusion records inspiration provenance separately from output colors. Naming a character, game, institution, or brand as inspiration does not grant permission to bundle its artwork, screenshots, logos, fonts, or other protected assets. A rights-safe named-theme example may retain user-authored mood words and color values while explicitly excluding third-party assets.
