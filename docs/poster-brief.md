# Poster Brief

The Poster Brief is the user-owned design intent established before content compression or layout. It records:

- audience and presentation setting;
- one-sentence takeaway;
- methods/results/impact emphasis;
- must-keep claims, figures, tables, and numbers;
- figure crop, split, or recomposition permission;
- logo mode;
- visual tone and palette inspiration;
- language and content mode;
- network and cloud permissions.

An agent may recommend values, but must show the resulting brief. Changing the confirmed brief invalidates hero selection and downstream design approvals.

Run `postex brief-questions` for the canonical interview prompts. See `schemas/poster-brief.schema.json` for the public contract.
