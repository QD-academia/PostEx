# PostEx v0.2.0a1 — Palette Fusion alpha

PostEx v0.2 turns visual inspiration into an explainable academic-poster design system while retaining evidence traceability, approval gates, editable PPTX output, and print preflight.

## Highlights

- Poster Brief interview for audience, takeaway, emphasis, must-keep evidence, figure-edit permission, logo treatment, and visual tone.
- Palette DNA with semantic roles, use ratios, moods, component behavior, provenance, simulations, and scientific-color locks.
- Palette Studio candidates: Academic Safe, Balanced Fusion, and Visual Signature.
- Three structurally different fusion directions: Hero Result, Visual Journey, and Editorial Story.
- Digest-bound hero-result, figure-edit, deletion, palette, and structure approvals.
- Locks for approved copy, figures, regions, palette colors, layout, and logos.
- Self-contained Palette Studio and design-rationale HTML reports.
- OpenAI and Anthropic provider boundaries through the shared Python core.
- Chinese/English input and output; A0, A1, and 36×48-inch landscape support.

## Included examples

- A rights-safe named-theme Palette Fusion example containing no proprietary character artwork.
- The separately licensed SCI02JITC real-paper golden example with editable PPTX, PDF, PNG, evidence, preflight, and approval records.
- Six licensed real-paper evaluation previews and one fictional evaluation case.

## Validation

- 16 unit and contract tests passed.
- Repository and all 10 public schema checks passed.
- Seven evaluation cases passed, including six real papers.
- Codex and Claude Code Skills passed validation.
- Ruff, editable package installation, CLI execution, and ZIP integrity checks passed.

## Alpha limitations

Palette Studio and fusion planning are runnable. The Bioinformatics Pipeline family remains the only production-renderable family in all three sizes. Rendering all three fusion directions, live color-vision and print simulations, and the production Observational Cohort family are planned for later v0.2 milestones.
