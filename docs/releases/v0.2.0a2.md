# PostEx v0.2.0a2 — rights-safe Palette Fusion rendering

PostEx v0.2.0a2 replaces the former real-paper golden example with AURORA-12, a fully fictional CC0 manuscript and evaluation fixture. It demonstrates how one approved evidence plan can support three coherent visual identities without changing scientific claims.

## Highlights

- Five-page AURORA-12 synthetic manuscript with stable evidence IDs and no DOI, participant, institution, external dataset, or real author.
- Three editable A0 posters: Academic Safe, user-image Balanced Fusion, and a no-green Paimon-inspired cape-gradient Visual Signature.
- Palette roles, component behavior, and stepped header gradients rendered through the shared Python core and native editable PowerPoint objects.
- Separate scientific-color unlock for editable SVG figure variants; numbers, labels, geometry, and evidence links remain unchanged.
- Digest-bound approvals for hero, deletion, palette, structure, and scientific-color changes.
- Portable render and extraction reports without machine-specific absolute paths.
- Editable logo placeholder retained in all three posters.

## Validation

- All unit, contract, repository, schema, and evaluation checks pass.
- All three PPTX files pass independent overflow checks.
- All three PDF/PNG exports pass A0 geometry, evidence, branding, approval, and print preflight.
- The Paimon-inspired palette and figure variant contain no green role or gradient stop.

## Boundaries

- The three posters share the approved Visual Journey structure; not every structural direction or template family is production-renderable yet.
- LibreOffice is the reproducible PDF-export fallback used for committed examples. PowerPoint remains preferred where available.
- The user-supplied image and HoYoverse reference images are not redistributed. Only abstract palette values and provenance records are included.
