# PostEx™ v0.4.0a1 — Trusted Export

Trusted Export makes source identity and release state part of the artifact rather than optional documentation.

- Posters show `Made with PostEx™ · PX-XXXXXXXX` by default.
- PPTX keeps the mark as `POSTEX_PROVENANCE_MARK`; PDF and PNG retain the render.
- An approved omission removes only the visible mark, never Manifest or file metadata.
- `postex-manifest.json` binds inputs, template, size, Palette ID, licensed materials, approvals, Preflight, and output hashes.
- ERROR blocks release-ready output; WARNING permits draft output only.
- Bioinformatics Pipeline, Observational Cohort, and Visual Results ship as real A0, A1, and 36×48 landscape assets with nine release-ready golden exports.
- `postex create <source>` creates a local project while leaving deletion, Palette Fusion, figure/scientific-color, structure, and final-release gates pending.

Legacy v0.3 projects remain valid and receive the provenance mark by default.
