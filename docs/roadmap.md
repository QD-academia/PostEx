# Roadmap

## v0.2 alpha 1 — design intelligence

Poster Brief, Palette DNA, three named Palette Studio expression levels with HTML preview, hero and figure approvals, three fusion directions, design locks, explainable HTML rationale, schemas, CLI, Skills, and tests.

## v0.2 alpha 2 — visual Palette Studio

Image extraction, live swatch/component simulations, color-vision-deficiency/grayscale/print rendering, natural-language palette revision, and role-aware renderer tokens.

## v0.2 beta — poster fusion

Render all three structural directions, automatic composite-panel detection, visual version diff, 3 m/2 m/1 m readability simulation, and production Observational Cohort family.

## v0.2 release

At least twelve licensed real-paper evaluations, both launch profiles end-to-end, cross-platform PowerPoint/LibreOffice checks, print samples, privacy review, and Codex/Claude Skill forward tests.

## Later

Visual Results family, conference packs, `.postex` reproducible project bundles, custom annotated templates, web review/collaboration, and ecosystem integrations.
