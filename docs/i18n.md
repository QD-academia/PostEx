# Chinese and English handling

PostEx v0.2 accepts `en` and `zh-CN` for input and output. Translation changes poster text but never evidence IDs, source locators, approval proposal IDs, locks, or numerical values.

Use language-aware font fallback and preflight every missing glyph. Avoid translating gene symbols, database identifiers, statistical notation, and established abbreviations unless a curated terminology record says otherwise. Preserve the original source excerpt hash in evidence reports.

The initial UI and report strings should be externalized before beta. Mixed-language manuscripts are valid; `input_language` identifies the dominant language.
