# PostEx launch kit

This kit contains reusable channel copy and a release checklist for the first Conference Intelligence and Genshin Study Identity campaigns. Replace every bracketed field, verify links, and keep one primary call to action per post.

## Message guardrails

Always preserve these distinctions:

- A palette card is not proof that a poster has been rendered.
- A Conference Pack may be verified or partially verified; unknown fields remain unknown.
- An organizer requirement is not a PostEx recommendation.
- A named visual inspiration does not create a license to redistribute third-party media.
- Genshin-inspired output is unofficial and implies no affiliation or endorsement.
- PostEx v0.5 is an alpha foundation; arbitrary conference-native PPTX geometry remains a Canvas Engine milestone.

Required notice for Genshin-inspired content:

> Genshin-inspired Palette DNA is an unofficial visual interpretation. Generated scientific posters do not embed character artwork by default, and no affiliation or endorsement is implied.

## Release checklist

### Product truth

- [ ] Version, feature status, and alpha boundary match the repository.
- [ ] Every named Conference Pack has the stated verification level.
- [ ] Every identity marked `ready` satisfies the campaign registry contract.
- [ ] No copy claims endorsement, partnership, or official template status.
- [ ] Unknown conference fields remain labeled unknown.

### Artifacts

- [ ] Poster PNG opens at the expected dimensions.
- [ ] PPTX is editable and opens without repair warnings.
- [ ] PDF and PNG match the approved visual direction.
- [ ] Evidence, preflight, and manifest links resolve.
- [ ] Social crops do not hide disclosures or distort figures.
- [ ] Alt text explains the scientific and visual comparison.

### Rights and privacy

- [ ] Rights manifest covers every redistributed source asset.
- [ ] Genshin-inspired posts include the required public notice.
- [ ] Character artwork is absent from generated posters unless separately approved.
- [ ] Scientific figures retain their allowed license and attribution.
- [ ] No personal, clinical, unpublished, or confidential data appears in the campaign.

### Distribution

- [ ] One primary CTA is selected for each post.
- [ ] Channel-specific copy replaces generic cross-posting.
- [ ] Current community self-promotion rules have been checked.
- [ ] Links are tested in a logged-out browser.
- [ ] GitHub Traffic baseline is captured before launch.
- [ ] A maintainer is available to answer questions after publication.

### After publication

- [ ] Record publication URL and time.
- [ ] Capture 24-hour and 7-day traffic, stars, clones, and requests.
- [ ] Convert repeated questions into documentation or issue templates.
- [ ] Prioritize the next identity or Conference Pack from observed demand.
